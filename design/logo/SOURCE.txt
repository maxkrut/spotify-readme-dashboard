BUILD
Run build.py with Python in an external environment containing fonttools and
uharfbuzz. Then run render.cjs with Node and an externally available Sharp package
(NODE_PATH can point to the existing runtime's node_modules).
No package installation, venv or node_modules is needed inside this repository.
For the second set use: build.py --set 2, followed by: node render.cjs 2.
Use set 3 for the recolored selection and set 4 for the new layouts.
Use build.py --set all, followed by node render.cjs all, to generate the complete page.

TYPOGRAPHY
All lettering uses Geologica 600. Axes: wght=600, CRSV=0, SHRP=0, slnt=0.
Kerning is retained; standard ligatures are disabled in both editable and outlined
versions. No synthetic bold, horizontal stretching or strokes around lettering.
Variant 13 rotates a complete word; variant 16 places individually rotated editable
letters along two arcs. Variant 14 includes a typographic fraction rule.
fonts/Geologica-variable.ttf is the original upstream font, not a dependency tree.
fonts/OFL.txt contains the SIL Open Font License and copyright attribution.
Font source:
https://github.com/google/fonts/tree/main/ofl/geologica
